# 무역 서류 다국어판 (분할 ml)

`../input_yamls`(영어 45건)와 같은 모양의 서식 5종을 11개 언어로 만든 합성 데이터입니다. Stanza 가 받는 12개 언어 가운데 영어는 기존 45건이 맡고, 여기는 한국어와 나머지 10개 언어입니다.

```
generate_trading_ml.py        시드 고정 생성기 (reportlab + PyYAML, Windows 글꼴)
packs/<언어>.py               서식 이름 · 용도 · 라벨 · 거래 값 · 질의 틀
input_yamls/<서식>_<언어>.yaml 정답. 키는 영어 서식과 같은 이름, 값은 그 언어
output_pdfs/<서식>_<언어>.pdf  렌더 결과. 라벨 · 날짜 · 숫자가 그 언어의 꼴
queries.yaml                  검색 질의와 정답 문서
```

다시 만들 때는 `python generate_trading_ml.py`, 저장된 파일과 같은지만 볼 때는 `--check` 를 씁니다. 번호는 언어 이름에서 뽑은 난수라 언어를 더하거나 고쳐도 다른 언어의 서류는 그대로이고, PDF 도 생성 시각을 고정해 같은 입력이면 같은 바이트가 나옵니다.

## 구성

언어마다 거래 하나(수출자 · 수입자 · 품목 2개 · 번호)를 두고 그 거래의 상업송장(CI) · 포장명세서(PL) · 선하증권(BL) · 원산지증명서(CO) · 적하보험증권(IP)을 씁니다. 11 × 5 = 55건.

|---|---|---|---|---|

- 정답 YAML 은 영어 서식과 키가 같아서 `eval/truth.py` 의 `trade_truth` 가 그대로 스키마 필드로 옮깁니다. 영어 서식 이름(`document_type`)을 그대로 두고, 그 언어의 이름은 `document_title`, 언어는 `language` 에 둡니다(정답 필드로는 쓰지 않음).
- 정답의 날짜는 ISO, 숫자는 숫자입니다. PDF 의 `11.09.2026` · `1.234,50` 같은 표기를 읽어 정규화하는 것이 파이프라인의 몫입니다.
- 보험 계약자는 CIF · CIP 면 수출자, 그 밖의 조건이면 수입자입니다.
- 질의(언어마다 17개): 식별자 5 · 서식 이름 5 · 용도 5 · 당사자 1 · 품목 1. 서식 이름 · 용도 질의는 언어를 고르지 않으므로 정답이 모든 언어의 같은 서식 11건입니다. 식별자 · 당사자 · 품목은 그 언어의 거래만 정답입니다.
- 평가: `make_plan.py trading|shipsearch --split ml`. 채점기(`score_trading.py`)는 문서에 언어가 있으면 언어별 줄을 덧붙입니다.

## PDF 렌더러

기존 서식과 같은 reportlab 로 씁니다. 앱은 PDF 의 글자 층을 `pdf-extract` 로 읽는데, 같은 HTML 을 Edge(Chromium) 로 인쇄한 PDF 를 같은 버전의 `pdf-extract` 로 읽어 보면 다음과 같이 깨졌습니다.

- 낱말 안에 공백이 낍니다: `B L-D E-260911`, `D eutschland` (글리프마다 위치를 따로 써서 생기는 틈)
- 아랍어가 표시형(presentation form) 글자 · 시각 순서(역순)로 나옵니다
- 일부 한자가 강희 부수 코드로 나옵니다: `⽇本`, `⽑重`

reportlab 은 모든 언어가 논리 순서 · 정상 코드로 나옵니다. 대신 아랍어 글자 잇기(shaping)를 하지 않아 **화면에서는 아랍어 글자가 떨어져 보입니다.** 글자 층은 바르므로 앱이 읽는 데는 문제가 없습니다. 실제 서류에는 브라우저 인쇄 PDF 도 흔하므로, 위 세 가지는 앱의 PDF 읽기에서 따로 다룰 거리입니다.

## 만들 때 지킨 것

- 회사 · 기관 · 선박 · 보험사 이름은 가상입니다. 상공회의소처럼 실제 기관이 떠오르는 자리는 지어낸 이름을 씁니다.
- 번호는 서식 · 언어마다 겹치지 않습니다(생성기가 확인).
- 영어 서식과 같은 키 · 구조를 지켜, 같은 채점기 · 정답 변환으로 언어만 바뀐 효과를 봅니다.

## 한계

- 언어마다 거래가 하나라 같은 언어 안의 서류는 당사자 · 품목이 같습니다. 문서를 가르는 것은 번호와 서식뿐입니다.
- 서식 5종만 있습니다(영어 45건은 45종).
- 번역은 원어민 검수를 거치지 않았습니다. 라벨은 그 나라 서식에서 흔한 말을 골랐지만 회사마다 다릅니다.
- 글꼴 경로가 Windows(`C:/Windows/Fonts`) 기준입니다.
