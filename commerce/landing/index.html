Python 불필요 No Python Required

Rust로 작성된 단일 네이티브 바이너리로 모델 로드, 스케줄링, 추론이 하나의 프로세스에서 완료됩니다.

A single native binary written in Rust handles model loading, scheduling, and inference entirely in one process.

OpenAI 호환 API OpenAI Compatible API

/v1/chat/completions 및 SSE 스트리밍을 지원하는 내장 서버. OpenAI SDK와 호환됩니다.

Built-in server supporting /v1/chat/completions and SSE streaming. Fully compatible with OpenAI SDK.

연속 배치 처리 Continuous Batching

기본값 parallel=4, 배치 프리필과 프롬프트 접두사 캐싱을 기본적으로 완벽하게 지원합니다.

Default parallel=4, with out-of-the-box full support for batched prefill and prompt prefix caching.
