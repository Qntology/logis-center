🚀 GitHub Repository HTML/CSS Template

GitHub의 Primer 디자인 시스템을 영감으로 제작된 모던한 저장소 대화형 HTML/CSS/JS 템플릿입니다. 실제 GitHub 저장소 인터페이스를 완벽하게 구현하여 포트폴리오, 문서 사이트, 클론 스터디용으로 자유롭게 활용하실 수 있습니다.

✨ 주요 기능 (Features)

  • Primer UI Aesthetics: GitHub 특유의 카드 구조, 테두리, 색상 팔레트 완벽 복제
  • Dark & Light Theme: 상단 해/달 아이콘을 클릭하여 실시간 테마 전환
  • Interactive File Explorer: 폴더 클릭 시 하위 경로 이동 및 파일 내용 즉시 확인
  • Tabs Navigation: Code, Issues, Pull Requests, Actions, Settings 탭 간 전환
  • Star/Fork Toggle: 별표 누르기 및 카운트 가상 연동

📦 빠른 시작 (Quick Start)

# Repository 클론하기

git clone https://github.com/octocat/github-ui-template.git

# 브라우저에서 index.html 파일 실행

open index.html
