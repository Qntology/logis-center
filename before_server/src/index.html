1. 보안 및 프라이버시 (가장 중요한 부분) Q: 정말로 제 데이터가 외부 서버로 전송되지 않나요? A: 네, 100% 로컬 환경에서만 작동합니다. 분석 대상인 무역 서류나 쇼핑몰 주문 데이터는 외부 클라우드로 업로드되지 않으며, 모든 AI 추론 프로세스는 작업 직후 메모리에서 완전히 파기(Atomic Purge)되어 흔적조차 남지 않습니다. Q: 인터넷 연결이 끊겨도 사용할 수 있나요? A: 당연합니다. 모델 로딩부터 데이터 추출, 로컬 DB 저장까지 모든 과정이 오프라인에서 가능하도록 설계되었습니다. 출장 중인 비행기 안이나 보안 구역 내에서도 업무를 중단 없이 수행하세요. 2. 하드웨어 및 성능 Q: 사양이 낮은 노트북에서도 잘 돌아갈까요? A: 일반적인 사무용 노트북에서도 원활히 작동합니다. 최적화된 0.8B 소형 LLM을 사용하므로, GPU VRAM 4GB 정도의 환경이면 충분합니다. 만약 GPU가 없는 환경이라도 'CPU 전용 모드'를 통해 안정적으로 작업을 마칠 수 있습니다. Q: AI를 오래 켜두면 컴퓨터가 느려지지 않나요? A: 저희 엔진은 매 루프마다 VRAM과 RAM을 강제로 초기화하는 'Deep Purge' 시스템을 갖추고 있습니다. 수백 건의 서류를 연속으로 처리해도 메모리 누수 없이 쾌적한 시스템 상태를 유지합니다. 3. 기능 및 활용 범위 Q: 어떤 서류들을 데이터로 변환할 수 있나요? A: 상업송장(CI), 포장명세서(PL), 선하증권(BL) 등 모든 무역 서류는 물론, 스마트폰으로 찍은 택배 운송장(Tracking) 사진도 정확히 인식합니다. 또한 복잡한 쇼핑몰 관리자 페이지의 주문 리스트도 버튼 하나로 정형 데이터로 변환할 수 있습니다. Q: HTML 구조가 복잡한 사이트에서도 잘 작동하나요? A: 저희만의 'Intelligent PUG Parser'가 지저분한 HTML 코드를 AI가 이해하기 쉬운 Pug 구조로 정밀하게 전처리합니다. 이를 통해 데이터 누락을 원천 차단하고 분석 정확도를 극대화했습니다. 4. 검색 및 관리 Q: 저장된 데이터는 나중에 어떻게 찾나요? A: 모든 데이터는 로컬 벡터 저장소(LanceDB)에 안전하게 아카이빙됩니다. "작년에 많이 팔린 무거운 제품 보여줘"와 같은 일상적인 자연어로 과거의 서류나 주문 내역을 1초 만에 검색할 수 있습니다. 5. 지원 파일 물류 송장/무역 문서 등의 이미지(PNG,JPG,PDF), 텍스트(웹 페이지) 등의 문서를 지원합니다. 권장사양 vram 4gb 이상(rtx 3050) ram 8gb 이상 지금 무료로 사용해보세요 시작하기
